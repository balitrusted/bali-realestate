# План запуска сайта в интернет (SEO-оптимизированный)

## ⚠️ ВАЖНО: Google Workspace НЕ обязателен для старта!

**Можно использовать обычный Google аккаунт** (gmail.com) для:
- ✅ Google Analytics
- ✅ Google Search Console
- ✅ Email уведомления (через Resend/SendGrid)

**Google Workspace нужен только если:**
- Хотите корпоративный email вида `info@yourdomain.com`
- Нужны корпоративные инструменты Google (Docs, Drive для команды)

**Вывод:** Можно запускать сайт БЕЗ Workspace! Email для уведомлений настроим через Resend (бесплатно до 3000 писем/месяц).

---

## 📋 План действий (пошагово)

### ЭТАП 1: Подготовка ДО деплоя (можно делать СЕЙЧАС)

#### ✅ 1.1. Проверка SEO-готовности сайта

- [x] Sitemap.xml (уже есть в `/sitemap.xml`)
- [x] Robots.txt (уже есть в `/robots.txt`)
- [x] Мета-теги на главной странице
- [ ] **ДОБАВИТЬ:** Страницы вилл в sitemap (каждая вилла должна быть в sitemap)
- [ ] **ПРОВЕРИТЬ:** Все страницы имеют уникальные title и description
- [ ] **ДОБАВИТЬ:** Структурированные данные (Schema.org) для вилл

#### ✅ 1.2. Настройка переменных окружения

Создайте `.env` с:
```env
ADMIN_PASSWORD=ваш_сложный_пароль
NEXT_PUBLIC_BASE_URL=https://yourdomain.com
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX  # Пока можно оставить пустым
```

#### ✅ 1.3. Подготовка домена (если есть)

- Купите домен (например, через Namecheap, GoDaddy, или прямо в Vercel)
- Пока можно деплоить на `yourproject.vercel.app` — домен подключите позже

---

### ЭТАП 2: Деплой на Vercel (можно делать БЕЗ Google Workspace)

#### ✅ 2.1. Задеплойте сайт

- Через Vercel CLI: `vercel`
- Или через веб-интерфейс Vercel

#### ✅ 2.2. Настройте переменные окружения в Vercel

- `ADMIN_PASSWORD` — сложный пароль
- `NEXT_PUBLIC_BASE_URL` — ваш домен или `https://yourproject.vercel.app`
- `BLOB_READ_WRITE_TOKEN` — добавится автоматически после создания Blob Storage

#### ✅ 2.3. Создайте Vercel Blob Storage

- Storage → Create Database → Blob
- Название: `bali-images`
- Регион: ближайший к вашим пользователям

---

### ЭТАП 3: Google Analytics (БЕЗ Workspace!)

#### ✅ 3.1. Создайте Google аккаунт (если нет)

- Зайдите на https://accounts.google.com
- Создайте аккаунт (можно обычный Gmail)

#### ✅ 3.2. Создайте ресурс GA4

1. Зайдите на https://analytics.google.com
2. Войдите своим Google аккаунтом
3. **Администратор** (шестерёнка) → **Создать ресурс**
4. Название: `Balitrusted`
5. Часовой пояс: ваш
6. Валюта: IDR или USD
7. Нажмите **Создать**

#### ✅ 3.3. Добавьте веб-поток

1. В созданном ресурсе: **Потоки данных** → **Добавить поток** → **Веб**
2. URL сайта: `https://yourproject.vercel.app` (или ваш домен)
3. Название потока: `Balitrusted Website`
4. Скопируйте **Идентификатор измерения** (G-XXXXXXXXXX)

#### ✅ 3.4. Добавьте ID в Vercel

- В Vercel Dashboard: **Settings → Environment Variables**
- Добавьте: `NEXT_PUBLIC_GA_MEASUREMENT_ID` = `G-XXXXXXXXXX`
- Перезапустите деплой (Redeploy)

#### ✅ 3.5. Проверка

- Откройте сайт в браузере
- В GA4: **Отчёты → В реальном времени** — через 1-2 минуты должен появиться активный пользователь

---

### ЭТАП 4: Google Search Console (БЕЗ Workspace!)

#### ✅ 4.1. Добавьте сайт в Search Console

1. Зайдите на https://search.google.com/search-console
2. Войдите тем же Google аккаунтом
3. **Добавить ресурс** → **Префикс URL**
4. Введите: `https://yourproject.vercel.app` (или ваш домен)

#### ✅ 4.2. Подтвердите владение сайтом

**Вариант 1: HTML-тег (проще)**
- Search Console предложит добавить тег в `<head>`
- Скопируйте тег
- Добавьте его в `app/layout.tsx` в секцию `<head>`
- Задеплойте
- Нажмите **Проверить** в Search Console

**Вариант 2: HTML-файл**
- Скачайте HTML-файл
- Загрузите его в `public/` папку проекта
- Задеплойте
- Нажмите **Проверить**

#### ✅ 4.3. Отправьте sitemap

1. После подтверждения: **Sitemaps** → **Добавить новый файл sitemap**
2. Введите: `https://yourproject.vercel.app/sitemap.xml`
3. Нажмите **Отправить**
4. Google начнёт индексировать страницы (займёт 1-7 дней)

---

### ЭТАП 5: Email для уведомлений (БЕЗ Workspace!)

#### ✅ 5.1. Настройте Resend (бесплатно до 3000 писем/месяц)

1. Зайдите на https://resend.com
2. Создайте аккаунт (можно через Google)
3. **API Keys** → **Create API Key**
4. Название: `Balitrusted Notifications`
5. Скопируйте ключ (начинается с `re_`)

#### ✅ 5.2. Добавьте домен (опционально, можно позже)

- **Domains** → **Add Domain**
- Введите ваш домен (например, `yourdomain.com`)
- Добавьте DNS-записи в настройках домена
- Подтвердите

#### ✅ 5.3. Обновите код отправки email

- В `.env` добавьте: `RESEND_API_KEY=re_xxxxxxxxxxxxx`
- Обновите `app/api/comments/notify/route.ts` для использования Resend
- (Можно сделать позже, пока уведомления будут в консоли)

### ЭТАП 6: Финальная проверка перед запуском

#### ✅ 6.1. Проверьте все страницы

- [ ] Главная страница открывается
- [ ] Каталог вилл работает (`/properties`)
- [ ] Страницы вилл открываются (`/properties/view/[id]`)
- [ ] Фильтры работают
- [ ] Админка доступна (`/admin/login`)
- [ ] Загрузка картинок работает

#### ✅ 6.2. Проверьте SEO

- [ ] Откройте `https://yourproject.vercel.app/sitemap.xml` — все страницы там?
- [ ] Откройте `https://yourproject.vercel.app/robots.txt` — правильный?
- [ ] Проверьте мета-теги: View Page Source → найдите `<title>` и `<meta name="description">`
- [ ] Проверьте в Google Search Console: **Покрытие** → нет ошибок?

#### ✅ 6.3. Проверьте скорость

- Зайдите на https://pagespeed.web.dev
- Введите URL сайта
- Проверьте мобильную и десктопную версии
- Исправьте критические проблемы (если есть)

### ЭТАП 7: Подключение домена (если есть)

#### ✅ 7.1. Добавьте домен в Vercel

1. Vercel Dashboard → **Settings → Domains**
2. Добавьте ваш домен (например, `balitrusted.com`)
3. Следуйте инструкциям Vercel для настройки DNS

#### ✅ 7.2. Обновите переменные

- В Vercel: `NEXT_PUBLIC_BASE_URL` = `https://balitrusted.com`
- Перезапустите деплой

#### ✅ 7.3. Обновите Google Search Console

- Добавьте новый ресурс с доменом (не .vercel.app)
- Подтвердите владение
- Отправьте sitemap снова
