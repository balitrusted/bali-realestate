# Настройка email-уведомлений

На сайте настроена отправка писем через **Resend**. Письма приходят в таких случаях:

| Событие | Кому |
|--------|------|
| Форма «Send Request» (страница /request) | На **ADMIN_EMAIL** |
| «Notify when available» на странице виллы | На **ADMIN_EMAIL** |
| Новый комментарий к статье | На **ADMIN_EMAIL** (на модерацию) |
| Ответ на комментарий | Автору исходного комментария (на его email) |

---

## Что сделать

### 1. Регистрация в Resend

1. Зайди на [resend.com](https://resend.com) и зарегистрируйся (можно через Google).
2. В меню: **API Keys** → **Create API Key** → скопируй ключ (начинается с `re_`).

### 2. Переменные в Vercel

В проекте на Vercel: **Settings** → **Environment Variables** → добавь:

| Name | Value | Зачем |
|------|--------|--------|
| `RESEND_API_KEY` | `re_xxxx...` (твой ключ) | Доступ к Resend |
| `ADMIN_EMAIL` | Твой email (например из Google Workspace) | Сюда приходят все уведомления с сайта |

Опционально:

- **`EMAIL_FROM`** — с какого адреса уходят письма. По умолчанию используется `onboarding@resend.dev` (работает без проверки домена). После проверки домена в Resend можно задать, например: `Balitrusted <notify@balitrusted.com>`.

### 3. Редеплой

После сохранения переменных сделай **Redeploy** проекта в Vercel.

---

## Проверка

- Отправь тестовую заявку с [balitrusted.com/request](https://balitrusted.com/request) — на **ADMIN_EMAIL** должно прийти письмо.
- Оставь комментарий к статье — на **ADMIN_EMAIL** придёт уведомление о новом комментарии.
- Ответь на чей-то комментарий — автору исходного комментария придёт письмо об ответе (если у него указан корректный email).

Если писем нет — проверь папку «Спам» и что в Vercel заданы именно `RESEND_API_KEY` и `ADMIN_EMAIL` и сделан редеплой.
