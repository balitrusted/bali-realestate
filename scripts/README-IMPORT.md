# Импорт объектов из CSV

## Как загрузить таблицу

1. Положите файл CSV в корень проекта и назовите его **`properties.csv`**  
   **или** укажите путь к файлу аргументом команды.

2. Откройте терминал и перейдите в папку проекта:

```bash
cd C:\Users\Professional\bali-realestate
```

3. Запустите импорт **одной** из команд:

**Вариант А** (если есть скрипт в package.json):
```bash
npm run import-csv
```

**Вариант Б** (всегда работает, без скрипта):
```bash
npx tsx scripts/import-csv.ts
```

Если CSV лежит не в корне проекта, укажите путь к файлу:
```bash
npx tsx scripts/import-csv.ts "C:\Users\Professional\Desktop\villas.csv"
```

3. Скрипт перезапишет файл **`data/properties.ts`** объектами из CSV.  
   Рекомендуется сделать резервную копию `data/properties.ts` перед первым импортом.

## Формат CSV

- Первая строка — заголовки колонок (регистр и символы `-`/`_` не важны).
- Ожидаемые колонки:  
  `villa_number`, `title`, `internal_name`, `description`, `object_type`, `deal_type`,  
  `main_area`, `sub_area`, `exact_location`, `display_location`,  
  `bedrooms`, `bathrooms`,  
  `price_monthly`, `price_yearly`, `price_currency`, `price_forsale`,  
  `duration_min`, `duration_max`, `order`,  
  `bathtub`, `car_parking`, `desk`, `nature_view`, `pool`.  
  Колонки `exact_location` (ссылка, например Google Maps) и `display_location` (широта,долгота) необязательны — можно оставить пустыми и заполнить позже в админке.

- Текст с запятыми или переносами строк заключайте в кавычки: `"Текст, с запятой"`.

### Кодировка, смайлы и удобства (галочки)

- **Сохраняйте CSV в UTF-8**, иначе буллеты, апострофы (Children's) и смайлы превратятся в знаки вопроса.  
  В Excel: «Сохранить как» → **«CSV UTF-8 (разделитель — запятая)»** или экспорт с кодировкой UTF-8.
- **Галочки** (bathtub, pool, desk и т.д.): в таблице указывайте «Да»/«Yes»/«true»/«1».  
  Если после старого импорта галочки не стоят — **запустите импорт заново** с текущим скриптом: логика распознавания «Да» исправлена, у всех вилл подтянутся правильные удобства.
- Фото в импорт не попадают — их нужно добавить потом в админке для каждого объекта.

## После импорта

- Запустите сайт (`npm run dev`) и проверьте каталог и карточки объектов.
- Фотографии добавьте вручную в админке: **Admin → Properties → Edit** у каждого объекта.
