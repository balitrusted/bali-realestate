# Подготовка к деплою

## 1. Пароль админки

Пароль задаётся переменной окружения **`ADMIN_PASSWORD`**.

### Сделать пароль сложным

1. Создайте или откройте файл **`.env`** в корне проекта (скопируйте с `.env.example`, если его ещё нет).
2. Задайте надёжный пароль:
   ```env
   ADMIN_PASSWORD=ваш_длинный_случайный_пароль
   ```
3. Рекомендации:
   - Не меньше 12–16 символов.
   - Буквы (A–Z, a–z), цифры и символы (!@#$% и т.п.).
   - Не используйте слова из словаря и личные данные.
4. Пример генерации (в терминале):
   - Windows (PowerShell): `[System.Convert]::ToBase64String((1..24 | ForEach-Object { Get-Random -Maximum 256 }) )`
   - Или онлайн: https://passwordsgenerator.net/

На продакшене **обязательно** смените дефолтный `admin123` и не коммитьте `.env` в git (он уже в `.gitignore`).

## 2. Google Analytics (счётчик статистики)

На сайте уже подключён компонент счётчика. Нужно только выдать ему ID вашего ресурса.

### Шаги

1. **Создайте ресурс GA4**
   - Зайдите на https://analytics.google.com/
   - Войдите в свой Google-аккаунт.
   - «Администратор» (шестерёнка) → «Создать ресурс».
   - Название, например: `Balitrusted`.
   - Часовой пояс и валюта — по желанию.
   - Создайте ресурс (без потока можно пропустить и добавить потом).

2. **Получите Measurement ID**
   - В этом ресурсе: «Настройки потока данных» или «Потоки данных» → добавьте «Веб».
   - Укажите URL сайта (например `https://yourdomain.com`).
   - Скопируйте **Идентификатор измерения** — он вида **`G-XXXXXXXXXX`**.

3. **Пропишите ID в проекте**
   - В корне проекта в файле **`.env`** добавьте (подставьте свой ID):
     ```env
     NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
     ```
   - Переменная должна начинаться с `NEXT_PUBLIC_`, чтобы быть доступной в браузере.
   - Перезапустите dev-сервер или заново соберите проект для продакшена.

4. **Проверка**
   - Откройте сайт в браузере.
   - В GA4: «Отчёты» → «В реальном времени» — через 1–2 минуты должен появиться активный пользователь.

Если переменная `NEXT_PUBLIC_GA_MEASUREMENT_ID` не задана, счётчик не подключается (ошибок не будет).

## 3. Перед выкладкой на хостинг

- В `.env` на сервере задайте:
  - `ADMIN_PASSWORD` — сложный пароль.
  - `NEXT_PUBLIC_BASE_URL` — ваш домен, например `https://balitrusted.com`.
  - При необходимости `NEXT_PUBLIC_GA_MEASUREMENT_ID` — для статистики.
- Убедитесь, что секреты не попали в репозиторий (`.env` в `.gitignore`).
